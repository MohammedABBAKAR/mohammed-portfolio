how I think.

1 / 5

Ask the right question

Before touching any data, I pin down the decision it should support: who will read the result, and what would change their mind.

  • KPI definition
  • Stakeholders

My rule: If I can't write the question in one sentence, I'm not ready to query.

2 / 5

Collect only what matters

I pull only what the question needs, straight from the source with SQL, and note where every column comes from.

  • SQL
  • Snowflake
  • Exports

My rule: Count rows at every step, so nothing disappears silently.

3 / 5

Clean and model

Most of the work lives here: duplicates, typos, date formats, missing values. Then I shape the tables into a clean model.

  • Power Query
  • Pandas
  • dbt

My rule: Every fix is written in code, never by hand in a cell.

4 / 5

Analyze and visualize

I look for the pattern that answers the question, then choose the simplest chart that shows it.

  • DAX
  • Python
  • Power BI

My rule: One page, one question.

5 / 5

Turn it into a decision

The result is a decision, not a dashboard: the finding, how sure I am, and what to do next.

  • Storytelling
  • Power BI report

My rule: Lead with the answer, then show the evidence.
